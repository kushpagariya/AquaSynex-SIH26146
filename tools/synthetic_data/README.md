# AquaSynex TraceGrid — Synthetic Data Generation & Scalability Suite

This directory contains the large-scale deterministic synthetic dataset generator and benchmarking tool for **TraceGrid (SIH26146)**.

All data generated by these tools is strictly synthetic research data modeling Bitcoin UTXO transactions, address clustering, network telemetry, and anomalous typologies. It contains **no real identities, no real private keys, and no real criminal claims**.

---

## Capabilities & Architecture

- **True Streaming Generation**: Uses buffered chunked writes (`io.BufferedWriter`) and bounded memory UTXO pools (< 50 MB RAM), enabling generation of **100K, 500K, 1M, and 2M+ rows** on standard development laptops without memory exhaustion.
- **Strict Ingestion Schema**: Emits standard 15-column SIH CSV files accepted directly by TraceGrid's `/api/datasets/upload` and DuckDB ingestion pipeline with zero schema modifications.
- **Deterministic & Reproducible**: Fully seeded pseudo-random generation. The same `(rows, seed)` pair produces the exact same byte-for-byte dataset.
- **Local MMDB Realism**: Network events use curated public IP ranges mapped across US, NL, IN, DE, FR, GB, SG, JP, AU, etc., that resolve against `GeoLite2-City.mmdb` and `ipinfo_lite.mmdb`.
- **Value Conservation**: Strict mathematical enforcement of Bitcoin conservation ($\sum \text{in} = \sum \text{out} + \text{fee}$) to the single satoshi.
- **Behavioral Scenarios**: Controlled typologies (`SCEN_NORMAL`, `SCEN_BURST`, `SCEN_FAN_IN`, `SCEN_FAN_OUT`, `SCEN_PEELING`, `SCEN_COORDINATED`, `SCEN_HIGH_VOL`, `SCEN_ADDRESS_REUSE`) with ground-truth records cataloged in `manifest.json`.

## Quick Start & CLI Usage

### 1. Generate 1,000 Rows (Smoke / Validation Test)
```bash
python tools/synthetic_data/generator.py --rows 1000 --out data/synthetic/1k/synthetic_1k.csv --seed 42
```

### 2. Generate 100,000 Rows
```bash
python tools/synthetic_data/generator.py --rows 100000 --out data/synthetic/100k/synthetic_100k.csv --seed 42
```

### 3. Generate 500,000 Rows
```bash
python tools/synthetic_data/generator.py --rows 500000 --out data/synthetic/500k/synthetic_500k.csv --seed 42
```

### 4. Generate 1,000,000 Rows (1M Scale Test)
```bash
python tools/synthetic_data/generator.py --rows 1000000 --out data/synthetic/1m/synthetic_1m.csv --seed 42
```

### 5. Generate 2,000,000 Rows
```bash
python tools/synthetic_data/generator.py --rows 2000000 --out data/synthetic/2m/synthetic_2m.csv --seed 42
```

## Benchmarking & Scalability Audit

Run the automated benchmark runner against any generated dataset:

```bash
python tools/synthetic_data/benchmark.py --csv data/synthetic/100k/synthetic_100k.csv --name "Scale-100K"
```

The benchmark runner measures:
1. **Ingestion Speed**: Ingestion throughput in rows/sec and MB/sec into DuckDB.
2. **Table Consistency**: Verifies transaction, input, output, network event, and address row counts.
3. **Query Latency**: Page 1 vs. Deep pagination (Page 100), TXID exact lookup, IP filter lookup, Network Map aggregation, and Graph neighborhood expansion.
4. **Scalability Invariant Audit**: Validates that APIs strictly enforce pagination and edge/node caps, guaranteeing that clients never receive millions of unpaginated records.
